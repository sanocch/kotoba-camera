# ことばカメラ

スマートフォンのカメラ映像を端末へ保存せず、画面内で一時停止してOCRするWebアプリの試作版です。

## 主な機能

- 背面カメラを起動
- 映像の1フレームをCanvasへ一時コピー
- 写真アプリ・ローカルストレージには保存しない
- 日本語・英語をブラウザ内でOCR
- 認識された単語を画像上または一覧から選択
- 日本語：読みの表示／読み上げ
- 英語：発音／日本語翻訳
- 翻訳を選ぶまでは翻訳処理を行わない

## 起動方法

カメラは安全なコンテキストが必要です。`index.html`を直接開くのではなく、HTTPSで公開するか、開発中はlocalhostで起動してください。

### Pythonでローカル起動

```bash
cd kotoba-camera
python3 -m http.server 8000
```

PCでは `http://localhost:8000` を開きます。

スマートフォンで試す場合は、GitHub Pages、Netlify、VercelなどHTTPS対応の静的ホスティングへフォルダ一式を公開してください。

## プライバシー

- カメラ画像はCanvasのメモリ上だけで扱います。
- `localStorage`、IndexedDB、ファイル保存、アップロード処理は使用していません。
- OCRと日本語の読み解析はブラウザ内で行います。
- 初回利用時はOCR言語データと日本語辞書をCDNから取得します。
- 「翻訳する」を押した場合のみ、選択した英語テキストを翻訳サービスへ送信します。画像は送信しません。
- Chromeの端末内Translator APIが利用できる場合はそちらを優先し、未対応ブラウザではMyMemory APIへ選択テキストを送ります。

## 注意点

- 手書き文字、縦書き、ルビ付き文章、光の反射、斜め撮影はOCR精度が下がります。
- OCRモデルと辞書は初回読み込み時に比較的大きな通信が発生します。
- iPhone Safariでは端末内Translator APIが使えないため、翻訳時のみ外部翻訳APIを利用します。
- 学校で正式運用する場合は、翻訳APIを学校管理のLibreTranslate等へ置き換えることを推奨します。
