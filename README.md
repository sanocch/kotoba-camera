# ことばカメラ v7

カメラ映像の上に、ブラウザ内OCRで検出した文字領域を四角い枠として表示します。枠をタップすると、その瞬間の映像をアプリ内だけに固定し、タップした文字だけを選択して「読みを表示」「読み上げる」「発音を聞く」「翻訳する」を実行できます。

## 主な動作

1. カメラを文字にかざす
2. 約2.8秒ごとに縮小フレームを端末内でOCR
3. 認識した文字に緑色の枠を表示
4. 読みたい枠をタップ
5. タップ時点の映像をCanvasに固定し、カメラを停止
6. タップした文字だけを処理

画像は写真アプリ、LocalStorage、IndexedDBへ保存しません。翻訳時だけ、選択した英語テキストを翻訳サービスへ送信する場合があります。画像は送信しません。

## 注意

初回はTesseract.jsの日本語・英語辞書を取得するため時間がかかります。ライブOCRは端末性能によって数秒間隔になります。枠を出したままカメラを大きく動かすと位置がずれるため、枠が出たら端末をできるだけ静止してタップしてください。
