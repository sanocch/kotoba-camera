# ことばカメラ v6

カメラ映像を端末へ保存せず、画面内で静止して文字を認識する学習支援Webアプリです。

## v6で追加した機能

- 縦書き・横書きの自動判定
- 横書き固定モード
- 縦書き固定モード
- 教科書モード（縦書きを優先）
- 0度・90度・270度でOCRを比較し、最も妥当な結果を採用
- 回転して認識した文字枠を元画像上の位置へ戻して表示

## 公開

GitHub Pagesでは、このフォルダ内のファイルをリポジトリ直下へアップロードしてください。

初回OCRでは日本語・英語辞書を読み込むため時間がかかることがあります。自動判定は複数方向を認識するため、横書き固定より処理時間が長くなります。
