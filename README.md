# ことばカメラ

カメラ映像を端末へ写真保存せず、ブラウザ画面内で静止してOCRする学習支援Webアプリです。

## 機能

- 背面カメラの映像を一時停止（写真アプリ・LocalStorageへ保存しません）
- 画像ファイルからの文字認識にも対応
- 日本語・英語OCR（Tesseract.js）
- 認識した文字を画像上または一覧から選択
- 日本語：読み仮名表示、読み上げ
- 英語：発音、選択後の翻訳
- 読み上げ速度、OCRモード変更
- PWA対応

## GitHub Pagesで公開

このフォルダの中身をリポジトリ直下へアップロードし、Settings → Pages → Deploy from a branch → main → /(root) を指定します。

公開URL例：`https://ユーザー名.github.io/kotoba-camera/`

## 注意

- カメラにはHTTPSが必要です。
- 初回OCR時は日本語・英語の辞書をCDNから読み込みます。
- 翻訳は対応Chromeではブラウザ内Translator APIを優先します。未対応時は選択した英語テキストだけを外部翻訳サービスへ送ります。画像は送りません。
- Google Sitesなどのiframe内ではカメラ権限が制限される場合があります。その場合は「別画面で開く」を使ってください。


## v3 修正

- iPhone・iPadで「画面を止める」後に静止画が黒くなる問題への対策を追加しました。
- カメラ映像を一時Canvasへ描画し、Blobで画素を確定してから表示用Canvasへコピーします。
- 静止画の描画完了後にカメラを停止します。
