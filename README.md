# ことばカメラ v8

Google Lensの文字選択に近い見え方を、読み上げに特化して単純化した版です。

## 操作
1. カメラを文字にかざして「画像を止める」
2. 認識された文字が白い枠で囲まれ、背景が暗くなる
3. 読みたい範囲の最初の文字をタップ
4. 読みたい範囲の最後の文字をタップ
5. 「読み上げる」を押す

同じ一文字だけを読む場合は、最初の文字を1回タップした時点で「読み上げる」を押せます。

画像は写真アプリやLocalStorageには保存しません。ページの一時メモリ上だけで扱います。
