# ことばカメラ Live v11（試作）

静止画像Canvasを表示せず、カメラ映像の上へOCR枠を重ねる試作版です。

## 操作
1. 文字にカメラをかざし、端末を止める
2. 「文字を探す」を押す
3. 白い枠から最初の文字をタップ
4. 最後の文字をタップ
5. 「読み上げる」を押す

最初の文字をタップした時点で video 要素を pause するため、その瞬間のカメラ表示が画面に残ります。表示用Canvasは使わないため、従来版の黒画面問題を避けます。

## 注意
- 初回はOCR辞書の読み込みに時間がかかります。
- 枠は「文字を探す」を押した時点の映像に対応します。枠が出るまで端末を動かさないでください。
- 画像は保存しません。OCR処理のため、非表示Canvasに一時コピーします。


## v11 の変更点

- カメラ領域内だけを1〜4倍に拡大
- 二本指のピンチ操作と＋／−ボタンに対応
- Webページ全体の拡大を防止
- 点線枠の内側だけをOCRし、選択範囲を限定
- 拡大後の表示と文字枠の座標を一致させる処理を追加
